Controls

Left click anywhere on a player formation to select it. Hold Shift to add or remove a unit.

Right click the field to move selected units, or an opponent unit to engage it. Archers stop and fire once their target is in range.

L / C switch selected units to line or column formation. WASD / arrows pan. Mouse wheel / + / − zoom. Space stops selected units. 0 fits the camera. P pauses.

Live units

Simulation, orders, formations, ranged and melee combat, casualties, morale, fatigue, routing, and rendering are Rust-owned. JavaScript only adapts browser input and updates this status panel.
