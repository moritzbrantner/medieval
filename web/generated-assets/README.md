# Medieval generated asset consumer proof

`medieval-camp-texture.asset.json` is a Medieval-owned visual asset specification consumed through the stable `asset-tooling` CLI contract.

The repository's dedicated asset consumer workflow pins `moritzbrantner/asset-tooling` to one exact commit, validates the spec, generates the SVG, and replay-verifies it. Generated bytes, receipts, and the content-addressed cache remain disposable and are not committed.

This asset belongs to presentation, not tactical truth. Medieval remains authoritative for battle rules and runtime semantics; `asset-tooling` owns only generation intent, provenance, cache integrity, and reproducibility evidence.
